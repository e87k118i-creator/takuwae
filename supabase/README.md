# Supabase 接続準備 (開発ブランチのみ)

- 接続先と公開用キーは `supabase/config.js` に配置済み。
- 公開用キーは秘密鍵ではないが、**RLSが適切に設定されるまでアプリからの書き込み・同期は絶対に有効にしない**。
- `supabase/schema.sql` は **未実行の提案SQL**。DBに適用済みではない。
- 現段階では本番版 v2.0.0、本番main、iPhoneの `localStorage` データは変更していない。
- このSQLの更新・削除権限は意図的に制限している。実際の同期には、版管理付きのRPC、取引冪等性、未送信キュー、初回移行とロールバック、認証設定の実装と動作検証が必要。
- 次のユーザー操作はSupabase Dashboardの「SQL Editor」への移動。SQLを実行する前にスキーマを確認し、バックアップを必ず取得する。
